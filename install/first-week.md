# Your first week

The system works best when each layer is trusted before the next one is added. A suggested first week:

| Day | Do this | What to check |
| --- | --- | --- |
| 1 | Finish the install. Run `/notion-update` at the end of every working chat. | The right project page got a Status, Open items and an Activity line. |
| 2 | Capture three or four notes on your phone into the Inbox. Run `/notion-inbox`. | Each note landed in the right place and left the Inbox. |
| 3 | Run `/notion-email`. | Notes on the right pages; new People rows for everyone you emailed; to-dos for things people asked of you. |
| 4 | Run `/notion-librarian`. | Names became links; duplicates were proposed, not merged on their own. |
| 5 | Run `/notion-eod` in the evening. Schedule it for weekday evenings. | One combined report; a Daily Journal row; suggested time entries. |
| 6 or 7 | Run the planning kickoff (`kickoff.md`), then `/month-plan` and `/week-plan`. | Goals has a month and week section; the dashboard shows the week. |
| 8 | Start each morning with `/day-plan`. | About six things, billable work first, and nothing saved until you said yes. |

When something is wrong, say so in plain words ("that's not my to-do", "never schedule calls before 10"). Claude records the correction where the skills will see it next time: on the Skill Run Log's Not to-dos list, on the Energy Plan, or on the Notion Map.
